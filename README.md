# Seal Studio

Seal Studio 是一个基于 Vue 3、Vite 和 Canvas 的中文印章生成器。所有印章绘制和手写签名处理都在浏览器本地完成，不依赖后端服务。

## 功能

### 公司印章

- 圆形章、圆形章（不带星）、椭圆章
- 单轮廓印章绘制
- 企业名称上半圆对称弧排
- 横排文字
- 下弦文支持圆弧和水平两种排列
- 备案码 / 防伪编号
- 朱红、宝蓝、黑色等颜色
- 透明度调节
- 0% - 100% 做旧程度调节
- 边缘断墨、掉墨颗粒、擦痕和像素级墨色衰减

### 个人印章

- 矩形、矩形（框）
- 方形大字、方形大字（框）
- 方形右大字、方形右大字（框）
- 16×16、18×18、20×20、22×22mm
- 姓名、姓名+印、姓名+之印
- 自动分栏和字号缩放，避免文字重叠

### 个人签名

- PC 端显示手机手绘签名入口和二维码
- 手机端可直接进入签名板
- 支持手指、触控笔和 Pointer Events
- 支持撤销、清空、颜色和笔触粗细调节
- 导出透明 PNG

## 技术栈

- Vue 3
- Vite
- Canvas 2D API
- `qrcode`：生成手机手绘签名入口二维码
- CSS 响应式布局

## 本地开发

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://localhost:5173/
```

如需让手机通过局域网访问，使用：

```bash
npm run dev -- --host 0.0.0.0
```

然后使用电脑的局域网 IP 访问，例如：

```text
http://192.168.1.100:5173/
```

PC 端二维码会使用当前页面地址生成。如果页面是通过 `localhost` 打开的，手机无法访问电脑的 `localhost`，需要先用局域网 IP 打开页面再扫码。

## 构建和预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/` 目录。

## 手机手绘签名地址

手绘签名页通过查询参数进入：

```text
/?mode=hand-sign
```

移动设备在屏幕较窄且支持粗指针时会自动进入手绘签名页；PC 端可以通过“个人签名”模块里的二维码进入。

## 绘制说明

公司印章和个人印章使用固定尺寸的 860×860 Canvas 作为绘制坐标系，再根据设备像素比设置实际画布分辨率。这样可以避免预览缩放导致文字位置漂移。

企业名称圆弧排版使用动态字符间角度，并以正上方为中心对称分布。做旧效果在完成印章绘制后读取 Canvas 像素，通过粗粒度噪声、细粒度噪声、透明度衰减和边缘断线模拟真实印泥缺墨。

## 注意事项

- 生成结果适合视觉设计、文档演示和图片叠加，不等同于具有法律效力的实体印章。
- 页面依赖浏览器 Canvas 2D API，建议使用较新的 Chrome、Edge、Firefox 或 Safari。
- 外部字体加载失败时会自动使用系统中文字体回退。
- 项目目前没有后端，用户输入不会自动保存；刷新页面会恢复默认配置。
